# JavaScript Events and Form Validation

Interactive simulation demonstrating core JavaScript event handling and client-side form validation for Web Technology II (CIAP).

## Live Demo
https://v3ravani.github.io/wt-ciap2/

## Topics Covered
- JavaScript Event Handling: `click`, `mouseover`, `dblclick`, `keydown`
- Client-Side Form Validation: `preventDefault`, regex pattern matching, error messaging

## Project Structure
- `index.html`: Page structure and markup
- `style.css`: Responsive design and UI styling
- `script.js`: Event listeners and form validation logic
